This is my own custom build of Firefox.  I am specifically adding a feature which allows named windows.  There are of course plugins that exist, however, these plugins plugins can only run code after Firefox has been initialized.  For my purposes I require that the initial title of the window be modified.  This allows for window manages such as as `i3`, `Sway`, and `Hyprland` to do things such as move windows to workspaces upon startup of Firefox.  This is not currently possible without very hacky solutions such as a watchdog program which detects if a Firefox window is "new", so in turn I decided to create an even hackier solution which is to modify how Session storing and restoration is handled.
